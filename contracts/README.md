# SettleX Smart Contracts

This directory contains the Solidity smart contracts, tests, and deployment scripts for SettleX.

## Layout

- `src/`: Solidity smart contracts (Escrow engine, dispute handling, milestone logic)
- `test/`: Foundry unit and integration tests
- `script/`: Foundry deployment and migration scripts

## Target Network

- **Network**: Monad Testnet (Chain ID: `10143`)
- **Solidity Version**: `^0.8.24`
- **Build & Test Tool**: Foundry (`forge`)

*Note: Smart contracts will be implemented in Phase 2.*
